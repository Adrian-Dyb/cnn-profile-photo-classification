# Repository checklist

Before publishing:

- [ ] Review `README.md` and optionally add your full name / university.
- [ ] Confirm that the public repository does not contain images you are not allowed to redistribute.
- [ ] Keep the full coursework dataset in the submission ZIP for the lecturer if required, but not necessarily in the public GitHub repository.
- [ ] Do not publish private or sensitive photos without consent.
- [ ] If you decide to publish `.pth` checkpoints, use Git LFS.
- [ ] Confirm that `results/results_summary.csv` matches the final experiment spreadsheet.
- [ ] Confirm that the report PDF is the final submitted version.

Suggested GitHub repository name:

`cnn-profile-photo-classification`
